CHARLES

개인용 콘텐츠 업로드 도구 · Personal content upload tool

CHARLES는 운영자 한 사람이 자기 PC에서 쓰는 개인 비서 프로그램입니다. 운영자가 직접 만든 영상을 운영자 본인의 YouTube 채널에 업로드하는 용도로만 Google 로그인(OAuth)을 사용합니다. 다른 사람에게 제공하는 서비스가 아니며, 다른 사람의 계정이나 데이터에 접근하지 않습니다.

CHARLES is a personal assistant program that a single operator runs on their own PC. It uses Google sign-in (OAuth) only to upload videos the operator made to the operator's own YouTube channel. It is not offered to other people and does not access anyone else's account or data.

이 앱은 YouTube API 서비스를 사용합니다. This app uses YouTube API Services.
